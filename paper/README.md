# Paper and validation data

- [article-en.pdf](article-en.pdf) — working draft (English, primary edition).
- [article-uk.pdf](article-uk.pdf) — Ukrainian working draft (parallel edition; numerical table bodies are generated from the same validated reference).
- `tex/en/main.tex`, `tex/uk/main.tex`, `tex/preamble.tex`, `tex/refs.bib` — LaTeX sources (XeLaTeX via Tectonic).
- `tex/tables/{en,uk}/` — table bodies generated by `tex/gen_tables.py` from the validated manuscript `article-ua.txt`; do not edit cells by hand.
- `article-ua.txt` — machine-readable Ukrainian manuscript whose tables are validated against the run data by `scripts/verify_tables.py` (1531 checks). The LaTeX tables are generated from it, so both editions carry exactly the validated values.
- `scripts/`, `data/`, `figures/` — experiment scripts, aggregated data and provenance, figures.

## Build

Install [Tectonic](https://tectonic-typesetting.github.io/), then from the repository root:

```bash
bash paper/tex/build.sh all        # or: en | uk
```

The first run downloads TeX packages and fonts into the Tectonic cache. The build regenerates the table bodies from `article-ua.txt`; it does not rerun experiments.

## Validate the tables

```bash
python paper/scripts/verify_tables.py --mode full \
  --data-dir release/evidence/full-20261013-r3/data \
  --article paper/article-ua.txt
```

Frozen evidence in `release/evidence/` keeps the original executed bytes; its recorded source hashes describe the executed snapshot, not later editorial changes to the manuscript.

This software release archives both manuscript drafts. Full content and visual
QA for publication of the paper remain a separate step; a software DOI does not
mark the manuscripts as final.
