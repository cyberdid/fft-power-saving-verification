# Прийняті результати full і незалежні перевірки

full-20261013-r3 — завершений 135-кроковий core-прогін. Абсолютні шляхи в manifest/collection є історичними шляхами машини виконання; файли перенесено без редагування, тому SHA256 у manifest.json стосуються саме цих файлів. Копію джерел (source/), з якої виконувався прогін, до репозиторію не включено, щоб не дублювати код; її хеші лишаються в manifest.json (source_sha256). Основні чисельні генератори після запуску не змінювалися. Актуальний verify_tables.py повторно перевірив повні дані з поточним рукописом.

Наведені JSON цілісності й перевірок є записами фактичних команд, не математичним доказом. 117 тестів у captured run та 123 тести поточного коду — різні зафіксовані стани. Стороннє навантаження на машину не контролювалося. Окремий streamed F_p1024 supplement — paper/data/supplemental/fp1024/, він не включений у core manifest.
